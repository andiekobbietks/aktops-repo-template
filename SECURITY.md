# Security policy

## Reporting a vulnerability

Please do not publish credentials, exploit details or sensitive vulnerability information in a public issue.

For security concerns affecting this repository, contact the repository owner through the private security reporting facilities available on the GitHub repository, if enabled. If private reporting is unavailable, contact the maintainer privately through a verified channel.

## Scope

Reports may include:
- Privileged workflow or token handling weaknesses.
- Governance policy bypasses or unsafe defaults.
- Script behaviour that could target the wrong repository.
- Supply-chain or dependency risks in this repository.

## Supported versions

The default branch is the active development baseline. No separate long-term support versions are currently declared.

## Operational note

Do not assume the presence of a security feature from documentation alone. Confirm that the relevant GitHub setting, workflow and repository entitlement are enabled in the adopting repository.
