## Scope convention

Documentation distinguishes between:
- **Implemented:** present in this repository and inspectable.
- **Operational prerequisite:** requires a GitHub permission, secret or platform setting.
- **Recommended:** a control an adopting team should consider.
- **Roadmap:** not yet implemented.

Do not treat a roadmap item as an existing security control.
